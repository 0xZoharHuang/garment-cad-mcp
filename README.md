# garment-cad-mcp

Agent-facing garment CAD toolchain built on Valentina and GarmentCode.

This repository provides:

- local MCP servers for professional 2D pattern CAD and 3D garment assembly;
- a typed Python SDK shared by MCP tools and pattern programs;
- transactional directory-based garment projects;
- the Valentina, Tape, Puzzle, and GarmentCode native GUIs;
- an optional remote NVIDIA GPU simulation worker.

The repository is currently intended for internal use. See `THIRD_PARTY.md` for upstream versions and licenses.
